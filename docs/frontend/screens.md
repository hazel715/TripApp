# 화면

컴포넌트 분해는 [components.md](./components.md). 인터랙션은 [interaction-rules.md](./interaction-rules.md).

레거시는 탭 3개(요약/일정/가계부) + 모달들이다. 신규는 가계부 중심.

## 정보 구조

1. **로그인**
2. **Project 목록** — 레거시에 없음
3. **Project 홈 / 지출 목록** — 레거시 `activeTab === 'account'`
4. **지출 작성/수정 모달** — `expenseModal`
5. **퀵메모 모달** — `quickMemoModal`
6. **정산 모달** — `showSettleModal`
7. **Project 설정** — 멤버, 기본 환율, 카테고리. 레거시는 상수
8. **확인 모달** — `confirmModal`

넣지 않음: 요약(숙소), 일정, 준비물, 일정 편집.

## 지출 목록 (MVP 핵심)

레거시 패턴을 유지한다.

- 상단: 그룹 셀렉트 (일자 / 결제자 / 카테고리)
- 그룹 헤더: 이름 + 기준통화 합계
- 행: 카테고리 뱃지, 제목, 환산 금액, 결제자, 참여자, 원 통화 금액
- 하단 고정 바: 총지출 + 정산하기
- FAB: 퀵메모, 추가
- 빈 상태: “지출 내역이 없습니다”

모바일에 맞춘 `max-w-md` 단일 컬럼은 유지해도 된다.

## 정산 모달

표 컬럼: 이름, 결제액, 실지출(부담), 정산액. 그 아래 송금 카드 `from → to` + 금액.

레거시 “확인 완료”는 닫기만 한다. 신규는 “닫기”와 “정산 확정”을 분리한다.

## 지출 폼

필드 순서 레거시와 동일하게 가져가도 된다: 결제자 | 카테고리, 일자, 제목, 금액 | 통화, 환율 박스, 포함 인원, 비고.

일자만 `type="date"` 로 바꾼다. 텍스트 `"4월 17일"` 입력을 제거한다.
