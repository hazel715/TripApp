# 화면

구현: `web/src`.

레거시 탭(요약/일정/가계부)은 사용하지 않는다.

## 정보 구조

1. Email login
2. Project 목록 / 생성
3. Project 상세 (멤버, 지출)
4. Expense 생성/수정/삭제, Share
5. Category 선택
6. 현재 부담 현황
7. 최종 정산 (최소 송금) — 명시적 버튼
8. 상단 변경 알림(bell)

## 지출 폼

결제자, 카테고리, 일자(`type=date`), 설명, 금액, 통화, 환율, 정산 금액/통화, 참여자별 share.

일자 기본값: 오늘. `"4월 17일"` 문자열 저장 없음.

## 입력 UI와 이름의 현재 상태 (2026-10-15)

화면/브라우저 제목의 TripApp을 제거하고 공동 정산을 임시 표기한다. 정식 타이틀은 추후 사용자가 정한다. 현재 통화는 직접 입력이며 결제 금액과 환율의 곱을 자동 제안하는 기능도 아직 없다. 주요 통화 선택과 Decimal 계산 제안 후 수정 UX가 후속 요구다. 정산 금액 override와 서버 Share 합 검증을 유지한다.
