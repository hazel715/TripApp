# 인터랙션 규칙

## 저장

- 상세 저장: 제목·금액·일자·결제자·참여자 ≥1 없으면 저장 버튼이 실패한다. 레거시는 타이틀/금액만.
- 신규 지출은 INSERT. 레거시 `arrayUnion`의 “동시입력 방어”는 행 INSERT로 대체.
- 수정은 PUT/PATCH. 레거시처럼 전체 배열 sort 후 통째 업로드하지 않는다.
- 퀵메모 성공 시 모달을 닫고 목록을 갱신한다. 파서 실패(금액 없음)는 저장하지 않고 메시지를 보여 준다. 레거시는 금액 0도 저장 가능하다 — 신규는 거부.

## 삭제

- 확인 모달 문구: 지출/멤버 구분.
- 정산된 지출 삭제 불가.

## 환율

- 통화 변경 시 기본 환율로 리셋. 커스텀 체크가 켜져 있으면 리셋할지 유지할지는 레거시와 같이 **리셋** (662행).
- 커스텀 해제 시 기본 환율로 되돌린다.

## 정산

- 미리보기는 GET/POST calculate. 지출을 바꾸지 않음.
- 확정은 별도 버튼. 실패 시 목록 불변.
- 송금 0건이면 레거시처럼 “완벽하게 정산되었습니다!” — 확정은 빈 Settlement를 만들 필요 없음.

## 날짜 표시

- 저장 값 `YYYY-MM-DD`
- 목록 그룹 키 표시 `MM-DD` 또는 `M월 D일` (로케일)
- 다른 연도가 섞이면 그룹 라벨에 연도 포함

## 접근

MVP 웹, 터치 우선. `max-w-md` 중앙 정렬 유지 가능.
